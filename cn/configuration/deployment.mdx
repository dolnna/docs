MemOS 提供三种方式获取运行中的记忆 API：使用无需管理基础设施的托管云服务、通过 Docker Compose 部署到可复现的自部署环境，或通过 pip 安装以获得最大灵活性。三种方式都暴露相同的 REST API 接口，因此您可以从云端开始，之后迁移到自部署而无需更改应用代码。

---

## 选项 1：MemOS 云端（托管）

最简单的选项 —— 无服务器、无配置、无依赖。在 [memos-dashboard.openmem.net](https://memos-dashboard.openmem.net) 注册，创建一个 API 密钥，并立即开始 API 调用。

云端 API 基础 URL 是 `https://api.openmem.net`。在每个请求的 `Authorization: Bearer` 头中使用您的 API 密钥。

如果您想快速上手、不想管理基础设施，或需要 OpenClaw 插件的跨设备记忆访问，这是正确的选择。

---

## 选项 2：Docker Compose（自部署推荐）

Docker Compose 是推荐的自部署方法。它在可复现的配置中将 MemOS 及其服务依赖一起启动。

<Steps>
  <Step title="克隆仓库">
    ```bash
    git clone https://github.com/MemTensor/MemOS.git
    cd MemOS
    ```
  </Step>

  <Step title="创建您的 .env 文件">
    在项目根目录创建一个 `.env` 文件。`.env` 文件必须在根目录中，而不是 `docker/` 子目录里。

    ```bash
    touch .env
    ```

    添加您的提供商凭证和配置。所有可用变量请参阅 [MemOS 环境变量参考](/cn/configuration/environment-variables)。最小示例：

    ```env
    OPENAI_API_KEY=your-api-key
    OPENAI_API_BASE=https://dashscope.aliyuncs.com/compatible-mode/v1
    MOS_CHAT_MODEL=qwen3-max

    MOS_EMBEDDER_BACKEND=universal_api
    MOS_EMBEDDER_MODEL=text-embedding-v4
    MOS_EMBEDDER_API_BASE=https://dashscope.aliyuncs.com/compatible-mode/v1
    MOS_EMBEDDER_API_KEY=your-api-key
    EMBEDDING_DIMENSION=1024

    MOS_TEXT_MEM_TYPE=naive_text
    DEFAULT_USE_REDIS_QUEUE=false
    ENABLE_CHAT_API=true
    ```
  </Step>

  <Step title="选择部署模式">
    `docker/` 目录包含两种模式：

    | 模式 | 描述 | 何时使用 |
    |---|---|---|
    | **Quick** | 轻量级。无 Neo4j。使用 `naive_text` 或 `general_text`。 | 开发、评估、不需要图记忆的部署 |
    | **Full** | 所有功能。包含 Neo4j 和完整依赖集。 | 使用 `tree_text` 记忆的生产环境 |

    两种模式都有用于 ARM 和 x86 架构的独立镜像变体。
  </Step>

  <Step title="启动服务">
    ```bash
    cd docker
    docker compose up
    ```

    Docker Compose 拉取所需的镜像，加载您的 `.env`，并启动所有服务。首次构建可能需要几分钟。成功启动后，您会看到：

    ```text
    INFO:     Uvicorn running on http://0.0.0.0:8000
    INFO:     Application startup complete.
    ```
  </Step>

  <Step title="验证部署">
    在浏览器中打开 `http://localhost:8000/docs` 以访问交互式 API 文档，并确认服务器正在运行。

    使用快速 curl 测试：

    ```bash
    curl -X POST http://localhost:8000/product/add \
      -H "Content-Type: application/json" \
      -d '{
        "messages": [{"role": "user", "content": "I prefer Python over JavaScript."}],
        "user_id": "user-123",
        "writable_cube_ids": ["your-cube-id"]
      }'
    ```
  </Step>
</Steps>

## 选项 3：pip 安装

当您想要在 Python 环境中直接运行 MemOS、将其集成到现有项目中或基于源代码开发时，请使用 pip。

<Steps>
  <Step title="创建 Python 环境">
    需要 Python 3.10 或更高版本。专用 Conda 环境可避免依赖冲突：

    ```bash
    conda create -n memos python=3.11
    conda activate memos
    ```
  </Step>

  <Step title="安装 MemoryOS">
    安装所有可选依赖：

    ```bash
    pip install -U "MemoryOS[all]"
    ```

    仅安装您需要的：

    ```bash
    # Tree memory (Neo4j) support
    pip install "MemoryOS[tree-mem]"

    # Async Redis scheduler
    pip install "MemoryOS[mem-scheduler]"

    # Memory Reader (document ingestion)
    pip install "MemoryOS[mem-reader]"

    # Multiple extras
    pip install "MemoryOS[tree-mem,mem-reader,mem-scheduler]"
    ```

    验证安装：

    ```bash
    python -c "import memos; print(memos.__version__)"
    ```
  </Step>

  <Step title="创建您的 .env 文件">
    在您的工作目录中创建一个 `.env` 文件并添加您的提供商凭证。所有可用变量请参阅 [MemOS 环境变量参考](/cn/configuration/environment-variables)。
  </Step>

  <Step title="启动服务器">
    MemOS 不会自动加载 `.env` 文件。使用 `python-dotenv` 在启动时注入变量：

    ```bash
    python -m dotenv run -- \
      uvicorn memos.api.server_api:app \
      --host 0.0.0.0 \
      --port 8000
    ```

    单 worker 配置（开发期间推荐）：

    ```bash
    python -m dotenv run -- \
      uvicorn memos.api.server_api:app \
      --host 0.0.0.0 \
      --port 8000 \
      --workers 1
    ```
  </Step>
</Steps>

## 服务依赖

根据您的记忆后端和配置，MemOS 可能需要额外的运行服务：

| 服务 | 何时需要 | 默认连接 |
|---|---|---|
| **Neo4j** | `MOS_TEXT_MEM_TYPE=tree_text` | `bolt://localhost:7687` |
| **Qdrant** | `MOS_TEXT_MEM_TYPE=general_text`，或与 `neo4j-community` 一起的 `tree_text` | `localhost:6333` |
| **Redis** | `DEFAULT_USE_REDIS_QUEUE=true` 或 `MOS_SCHEDULER_USE_REDIS_QUEUE=true` | `localhost:6379` |

如果您使用 `MOS_TEXT_MEM_TYPE=naive_text` 并 `DEFAULT_USE_REDIS_QUEUE=false`，除了 MemOS 服务器本身外，不需要外部服务。

---

## 访问运行中的服务器

| 资源 | URL |
|---|---|
| Memory API | `http://localhost:8000` |
| 交互式 API 文档 (Swagger) | `http://localhost:8000/docs` |

<Note>
  默认端口是 `8000`。要在不同端口上运行，请更改 uvicorn 命令中的 `--port` 标志或更新 Docker Compose 文件中的端口映射。
</Note>
