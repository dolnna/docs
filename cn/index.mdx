MemOS 是一个为 LLM 和 AI Agent 提供持久化、上下文感知记忆的记忆操作系统。通过一个 REST API 或 Python SDK，您可以从对话中添加记忆，进行语义搜索，并将其反馈给您的 Agent —— 从而实现可随时间进化的个性化、有状态的 AI 交互。

## 三步开始使用

<Steps>
  <Step title="获取访问权限">
    在 [memos-dashboard.openmem.net](https://memos-dashboard.openmem.net) 注册以获得云端访问权限，或通过 Docker 或 pip [自部署](/cn/installation)。
  </Step>
  <Step title="添加您的第一条记忆">
    发送一个带有对话消息的 `POST /product/add` 请求。MemOS 会自动提取并存储记忆。
  </Step>
  <Step title="搜索并使用记忆">
    使用 `POST /product/search` 查询以检索相关记忆 —— 将它们注入您的 LLM 以获得上下文感知的响应。
  </Step>
</Steps>

<Note>
  MemOS 同时支持 **云端 API**（托管，无需管理基础设施）和在您自有基础设施上的 **自部署**。两种方式的 API 接口完全相同。
</Note>
