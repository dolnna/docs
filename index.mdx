MemOS is a Memory Operating System that gives LLMs and AI agents persistent, context-aware memory. With a single REST API or Python SDK, you can add memories from conversations, search them semantically, and feed them back into your agent — enabling personalized, stateful AI interactions that improve over time.

## Get started in 3 steps

<Steps>
  <Step title="Get access">
    Sign up at [memos-dashboard.openmem.net](https://memos-dashboard.openmem.net) for cloud access, or [install self-hosted](/installation) via Docker or pip.
  </Step>
  <Step title="Add your first memory">
    Send a `POST /product/add` request with a conversation message. MemOS extracts and stores the memory automatically.
  </Step>
  <Step title="Search and use memory">
    Query with `POST /product/search` to retrieve relevant memories — feed them into your LLM for context-aware responses.
  </Step>
</Steps>

<Note>
  MemOS supports both a **Cloud API** (hosted, no infrastructure to manage) and **self-hosted** deployment on your own infrastructure. The API surface is identical either way.
</Note>
